# v0.9.0c — coupled resistance closure (reduced model)

## Scope and design
The v0.9.0b corrected radial surface reconstruction and axial half-cell terms are retained. Instead of a terminal additive correction, a global history state x evolves as dx/dt=a(|j|)(1-x)-d(|j|)x; learned nonnegative recovery d changes x. A spatially varying positive interfacial resistance is inserted directly into the linearized reaction operator K=A+n*1.2*x*diag(0.5+cell_center). K p + V 1 = U(c_surface), sum(p)=J. Local p supplies each radial particle's conservative boundary flux, so the learned closure changes subsequent concentration and reaction distributions. The fixed spatial pattern and global state are supplied; no locally learned constitutive law, nonlinear Butler–Volmer kinetics, or full P2D claim. All parameters are normalized illustrative values, not material measurements.

Time stepping uses exact radial diffusion propagators for piecewise constant local source and an exponentially propagated midpoint reaction solve (second-order candidate; convergence tested, not analytically guaranteed). Exact global-state update over held applied-current intervals. Power identity U^T p - V J = p^T K p >=0 tests resistive passivity, not full thermodynamic energy conservation. Sampled concentration bounds are checked, not guaranteed everywhere between outputs.
