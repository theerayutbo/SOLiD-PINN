## Protocol and scientific scope

Synthetic state dx/dt=a*j^2/(1+b*j^2)*(1-x)-c*x^3-d(|j|)*x, with known observation map from v0.8.6. True a=.1, b=.7, c=.06; d is zero (null falsification), .10/(1+(j/.8)^2) (rest recovery), or .012+.09*exp(-(j-1.2)^2/.65) (peaked recovery), in inverse hours. All illustrative, not measured ASSB mechanisms. The correction placement and sign are supplied to all closure models, not discovered. No latent labels used for fitting; x is algebraically observable at nonzero current given the supplied voltage map and unobservable during rest in that map. Reference uses adaptive solve_ivp; fitting uses RK4 .5h substeps.

Six training current profiles, 222 voltage points including rests; two independent noisy validation profiles, 74 points; held-out two interpolation, two mixed extrapolation to 4 mA/cm2, two recovery profiles. Nonzero validation current magnitudes disjoint from training and interpolation/extra test magnitudes. Three paired noise seeds 11,23,37, SD 1 and 5 mV. Same train/validation data across methods. No test labels or true closure values in non-oracle optimization/selection. Fitted baseline parameters a,b,c are shared in form, not frozen, for calibrated, constant, linear, RBF and oracle. Nominal has exactly true baseline coefficients and no missing term (strong null control). Constant closure fits one nonnegative coefficient. Piecewise linear fits five nonnegative nodes with endpoint clipping. RBF neural closure is a fixed-width, fixed-center radial basis network with four trainable nonnegative output weights, no learned hidden layer, bounded least squares through ODE. Smoothness lambdas 0,10,50 independently selected by noisy validation voltage for linear and RBF; selection only among converged candidates. Oracle is given true shape and fits its amplitude and baseline coefficients; in null case amplitude structurally unidentifiable. This is a solver-integrated neural closure/UDE, not a collocation PINN. Pure data neural baseline, richer learned network, closure-selection test and dynamic PINN are deferred.
